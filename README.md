# Lavanda Suite · Registro de huéspedes

Formulario que completan los huéspedes de Lavanda Suite (Villa Gesell) desde el link personal que
reciben por WhatsApp. Los datos se guardan en Firestore, protegidos por reglas de acceso; este
repositorio solo tiene la página, sin datos de huéspedes.

El código fuente vive en el repo de la app (`web/registro`); acá se publica con GitHub Pages.
